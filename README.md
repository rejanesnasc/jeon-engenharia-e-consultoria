# Sobre o projeto

Este repositório corresponde ao website institucional da JEON Engenharia & Consultoria, voltado à apresentação da empresa e de sua atuação em consultoria técnica relacionada a ativos de transmissão de energia elétrica em alta tensão.

# Público-alvo
O website é direcionado a organizações e profissionais do setor elétrico interessados em consultoria e suporte técnico especializado, especialmente no contexto de ativos e infraestrutura de transmissão.

Acesso à versão publicada
O website pode ser acessado em: https://jeon-engenharia-e-consultoria.vercel.app/

A URL acima corresponde à versão pública hospedada na plataforma Vercel.
Site publicado: https://jeon-engenharia-e-consultoria.vercel.app/

# Como Rodar Localmente
1. Clonar o repositório: git clone https://github.com/xxxx

2. Entrar na pasta do projeto
jeon-engenharia-e-consultoria

3. Instalar dependências
npm install

4. Rodar o servidor de desenvolvumento
npm run dev

5. Acessar no navegador
http://localhost:5173/

# Rodando Testes
Executar a todos os testes 
npx vistest run

Modo watch (desenvolvimento)
npx vistest

Com interface visual
npx vitest --ui

#Gerar relatório de cobertura
npx vitest run --coverage

# Diretrizes de conteúdo
As atualizações do website devem preservar:
- A precisão das informações técnicas e institucionais.
- Uma linguagem clara, objetiva e compatível com o setor de engenharia.
- A consistência visual e terminológica da marca JEON.
- A revisão de links, informações de contato e versões para diferentes dispositivos.
- A acessibilidade e a legibilidade dos conteúdos.
